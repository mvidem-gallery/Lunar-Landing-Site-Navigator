# LWP Mission Datatable

Веб-таблица на чистом JavaScript (без сборки и внешних зависимостей) для анализа, фильтрации и сравнения JSON-логов миссий формата `lwp-flight/2` (из проекта `launch-window-prediction`).

## Запуск

Откройте [index.html](./index.html) двойным кликом в любом современном браузере (работает напрямую по `file://` и через любой HTTP-сервер).

При старте автоматически загружается демонстрационный снимок на основе `flight-2026-11-15T163612Z.json`. Чтобы загрузить полный лог (включая все записи `log`) или сравнить несколько миссий, перетащите JSON-файлы в зону загрузки или нажмите **«+ Загрузить JSON»**.

## Возможности

1. **Сводка миссий (`Missions`)**
   - Сравнение нескольких загруженных логов в одной таблице.
   - Автоматическая подсветка минимального `Δv миссии` и минимального времени перелёта (`MIN`).
   - Поиск и фильтрация по статусу, режиму (`economy` и др.), космодрому и ракете.
   - Сортировка по любой колонке и экспорт в CSV.
   - Боковая панель деталей выбранной миссии (разбивка `Δv`, параметры орбиты Луны, условия освещённости Солнца и Земли, аргументы запуска).

2. **Варианты и Таймлайн (`Variants & Timeline`)**
   - **Таймлайн полёта** (`summary.timeline`) — этапы от старта до посадки с `T+`.
   - **Окна по датам** (`summary.economy.days`) — перебор сдвигов дат, причины отказов и отметка выбранного дня (`CHOSEN`).
   - **Сравнение космодромов** (`summary.spaceports_compared`) — `Δv` и даты запуска/посадки по космодромам.

3. **Лог расчётов (`Calculation Log`)**
   - Пагинация (50 / 100 / 250 / 500 строк на страницу) для работы с большими массивами `log` (45k+ строк).
   - Фильтр по типу события (`event`) и полнотекстовый поиск.
   - Клик по строке раскрывает/сворачивает отформатированный JSON поля `data`.

## JS API для интеграции

Проект готов к приёму логов из внешней программы или WebView двумя способами:

1. **Прямой вызов в `window`:**
   ```js
   window.MissionDatatable.ingest(jsonObject, { filename: 'flight-2026-11-15T163612Z.json' });
   window.MissionDatatable.ingestBatch([{ json: obj1, meta: { filename: 'a.json' } }]);
   ```
2. **Через `window.postMessage`:**
   ```js
   window.postMessage({
     type: 'LWP_INGEST_LOG',
     filename: 'flight-2026-11-15T163612Z.json',
     payload: jsonObject,
   }, '*');
   ```

## Структура файлов

- `index.html` — разметка интерфейса
- `styles.css` — стили таблиц, фильтров и панели деталей
- `js/parser.js` — парсер и нормализатор формата `lwp-flight/2`
- `js/store.js` — хранилище миссий и публичное API (`window.MissionDatatable`, `postMessage`)
- `js/datatable.js` — сортировка, рендеринг таблиц и экспорт в CSV
- `js/sampleData.js` — демонстрационные данные из `flight-2026-11-15T163612Z.json`
- `js/app.js` — контроллер вкладок, фильтров и UI
